# MEPhI_ROS2_drone_firmware

Здесь содержится прошивка для отладочной платы Arduino UNO R3. В файле [`Инструкция по прошивке отладочной платы Arduino UNO R3.pdf`](/andino_firmware/Инструкция%20по%20прошивке%20отладочной%20платы%20Arduino%20UNO%20R3.pdf) подробно описано как прошить плату.

## Отладочные команды

С помощью `Serial Monitor` в Arduino IDE при выставленной скорости `57600 baud` и режиме `Carriage return` можно отправлять отладочные команды на микроконтроллер и получать ответные данные (Arduino UNO R3 должна быть присоединена к USB порту вашего компьютера).

  - чтение статуса аналоговых пинов Arduino UNO R3: `a`
  - чтение статуса цифровых пинов Arduino UNO R3: `d`
  - чтение текущего положения энкодеров: `e`
  - сброс положения энкодеров в ноль: `r`
  - выставление скорости вращения колес в `тиках_энкодера/сек`: `m 5400 5400`
  - выставление скорости вращения колес заполнением ШИМ: `o 255 255`
  - задание коэффициентов PID регулятора: `u 1:2:3:4`
  - определение статуса IMU: `h`
  - чтение данных с IMU: `i`
